# Dataset

1. Dataset: IBM Credit Card Fraud Detection  
2. Link: https://www.kaggle.com/code/yichenzhang1226/ibm-credit-card-fraud-detection-eda-random-forest/input
3. Source: Kaggle

## Description

This dataset contains information about credit card transactions, customers, cards, merchants, transaction amounts, dates, and fraud indicators.

## Main Data

- users.csv
- cards.csv
- credit_card_transaction.csv

## Dataset Size

The transaction dataset contains approximately **24.39 million transactions records** and is **2.2 GB** raw & **3.4 GB** cleaned combined is around **5.6 GB** in size. That is why the raw and cleaned transaction data are not included in this repository due to the large file size.

## Usage

The dataset was used for data cleaning, SQL analysis, fraud and transaction analysis, and Power BI dashboard development.
